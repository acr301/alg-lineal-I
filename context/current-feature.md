# Current Feature: Eliminación Gaussiana Interactiva (semana2/tarea1)

## Status

In Progress

## Goals

- Programa interactivo en Python (semana2/tarea1/) que resuelva sistemas Ax=b.
- Implementar eliminación por filas (reducción a forma escalonada) con pivoteo parcial.
- Mostrar los pasos del proceso de reducción (didáctico, consolidando los pasos lógicos del método).
- Clasificar el sistema: compatible determinado (solución única), compatible indeterminado
  (infinitas soluciones, con solución paramétrica) o incompatible (sin solución).
- Separar lógica pura (algoritmo) de la interacción por consola (input/print) para que sea testeable.

  para la lógica de resolución). Solo estructuras elementales: listas, bucles, condicionales,
